# TriAgent-Driven Development Bundles

Reusable workflow bundles for the TriAgent-Driven Development skill.

## Layout

- `source/triagent-driven-development/`
  Shared workflow, agents, and installation guides for Codex and OpenCode.

## Install

From the repository root, choose your tool and read its install guide:

### OpenCode

```bash
cat source/triagent-driven-development/README_OPENCODE_INSTALL.md
```

### Codex

```bash
cat source/triagent-driven-development/README_CODEX_INSTALL.md
```
